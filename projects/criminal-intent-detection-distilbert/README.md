# Fine-tuning DistilBERT for Multi-Class Criminal Intent Detection in Dialogue

## Overview
Automatic detection of criminal intent in conversational text is crucial for proactive risk assessment and digital safety systems. This project fine-tunes **DistilBERT**, a lightweight transformer model, to classify dialogue into multiple criminal intent categories.

The approach balances performance and computational efficiency while maintaining strong contextual understanding of conversational language.

---

## Problem Statement
Rule-based systems and traditional machine learning models struggle to capture contextual nuances and intent in dialogue.

**Objective:**  
To fine-tune a transformer-based model capable of accurately identifying and classifying criminal intent from conversational text.

---

## Methodology
- Preprocessed dialogue datasets through tokenization, normalization, and sequence truncation.
- Fine-tuned DistilBERT using supervised learning for multi-class intent classification.
- Applied class weighting and regularization to improve generalization.
- Evaluated performance using precision, recall, F1-score, and confusion matrices.

---

## Tools & Technologies
- **Programming Language:** Python  
- **Libraries & Frameworks:** Hugging Face Transformers, PyTorch, Scikit-learn  
- **Techniques:** Transformer Models, Text Classification, Transfer Learning, NLP  

---

## Results
- Achieved robust multi-class intent classification with strong contextual accuracy.
- Demonstrated improved performance over baseline machine learning models.
- Validated model reliability through comprehensive evaluation metrics.
