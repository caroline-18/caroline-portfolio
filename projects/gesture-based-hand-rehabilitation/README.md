# Kinetic Command: A Real-Time, Gesture-Based System for Gamified Hand Rehabilitation Using MediaPipe and OpenCV

## Overview
Hand rehabilitation plays a critical role in recovery from neurological and musculoskeletal conditions. Traditional rehabilitation exercises often lack engagement and real-time feedback, reducing patient adherence.

This project presents a **real-time, gesture-based hand rehabilitation system** that leverages computer vision techniques to track hand movements and convert rehabilitation exercises into interactive, gamified tasks.

---

## Problem Statement
Conventional rehabilitation methods provide limited feedback and motivation, making it difficult for patients to consistently perform therapeutic hand exercises.

**Objective:**  
To develop a computer vision–based system that accurately tracks hand gestures in real time and promotes patient engagement through gamification.

---

## Methodology
- Captured real-time video input and detected hand landmarks using MediaPipe.
- Tracked finger and joint movements to recognize predefined therapeutic gestures.
- Implemented gesture validation logic using OpenCV to measure movement accuracy and consistency.
- Designed a gamified interaction framework to provide instant feedback and progress tracking.

---

## Tools & Technologies
- **Programming Language:** Python  
- **Libraries & Frameworks:** MediaPipe, OpenCV, NumPy  
- **Techniques:** Computer Vision, Hand Landmark Detection, Real-Time Systems, Human–Computer Interaction  

---

## Results
- Achieved accurate real-time hand gesture detection with low latency.
- Enabled quantitative tracking of hand movement precision and repetition.
- Improved engagement by integrating rehabilitation tasks into interactive game-like scenarios.
