# Data-Driven Employee Retention: An Explainable Machine Learning Approach

## Overview
Employee attrition poses a significant challenge for organizations, impacting productivity, operational costs, and workforce stability. This project applies **machine learning and explainable AI (XAI)** techniques to predict employee attrition while providing transparent insights into the factors influencing retention decisions.

The emphasis is on building accurate predictive models that are interpretable and actionable for human resource management.

---

## Problem Statement
Traditional attrition prediction models often function as black boxes, limiting their usefulness for strategic decision-making.

**Objective:**  
To develop an explainable machine learning framework that accurately predicts employee attrition and highlights the key factors driving employee turnover.

---

## Methodology
- Collected and preprocessed structured HR data, including demographic, performance, and compensation features.
- Trained and compared multiple machine learning models such as Logistic Regression, Random Forest, and XGBoost.
- Addressed class imbalance using resampling techniques to improve predictive reliability.
- Applied SHAP-based explainability methods to interpret model predictions at both global and individual levels.

---

## Tools & Technologies
- **Programming Language:** Python  
- **Libraries & Frameworks:** Scikit-learn, XGBoost, SHAP, Pandas, NumPy  
- **Techniques:** Machine Learning, Feature Engineering, Class Imbalance Handling, Explainable AI  

---

## Results
- Achieved reliable attrition prediction performance across multiple models.
- Identified key retention drivers such as job role, compensation, workload, and career progression.
- Generated interpretable explanations to support data-driven HR policy and retention strategy design.
