# Machine Learning Model for Emotion Recognition Using Text and Support Vector Machine

## Dataset Description

The dataset consists of text samples annotated with emotion labels such as joy, sadness, anger, fear, and neutral.

Each record contains:
- Text input (sentence or short paragraph)
- Emotion label (categorical)

The dataset is used for supervised emotion classification from text.

## Preprocessing
- Lowercasing
- Removal of punctuation and stopwords
- Tokenization
- Vectorization using TF-IDF

## Source
Publicly available emotion / sentiment text datasets (e.g., social media or dialogue-based corpora).

Note: Raw data is not included in this repository and should be obtained from public sources.
