## Dataset Description

The dataset consists of text samples annotated with emotion labels such as joy, sadness, anger, fear, disgust, surprise, and neutral.

Each record contains:
- Text input (sentence or short paragraph)
- Emotion label (multi-class)

## Preprocessing Steps
- Lowercasing
- Punctuation and stopword removal
- Tokenization
- Lemmatization
- TF-IDF vectorization

## Source
Publicly available emotion-labeled text datasets (e.g., social media or dialogue-based corpora).

Note: The raw dataset is not included in this repository due to licensing constraints.
